# V2.2 — Mockups needed

**Date:** 2026-11-26. **Status (2026-11-27): drawn.** The mockups are in `resources/mockups/v2/` (HTML in `html/`, PNGs of every state), mapped in `resources/mockups/README.md`. This is the list of screens to draw before V2.2 is built. They are used in the same way as the V1 mockups (`resources/mockups/README.md`).

**How to read this list**
- Each line is one image. Draw a **desktop** and a **mobile** version unless the line says otherwise.
- **Design rules:** `resources/DESIGN_GUIDE.md` (colors, type, spacing, components, V2.2 patterns). **Current look:** `resources/screenshots/`.
- Use the V1 style: the same sidebar, cards, colors, buttons and tables as `resources/mockups/dashboard.png`, `resources/mockups/event_layout.png` and the others.
- Suggested file names follow the existing pattern. When the images are ready, I add them to `resources/mockups/README.md`.
- **Priority:** A = needed before building; B = helpful, but I can build it from existing patterns if it's missing; C = optional.

Where a sketch is given, it shows *what goes on the screen*, not how it should look.
